🔍 Anomaly Detection Comparison

🎓 Why Isolation Forest Fails at Energy Waste Detection

Isolation Forest (Precision: 1.28%) is an unsupervised density estimator. It isolates any statistically rare point in the feature space — this includes power outages, extreme heat spikes, and packed-auditorium events. None of these represent electricity waste.


Contextual ML Detector (Precision: 93.18%) directly answers the correct question: "Is there excess power draw specifically when the space is empty?" The dual condition (residual ≥ threshold AND occupancy ≤ limit) eliminates false alarms from legitimate high-load events, achieving F1 = 0.9647 on the test set.


⚠️ High accuracy (0.9323 for Isolation Forest) can be misleading in imbalanced datasets where anomalies are rare. Always evaluate precision, recall, and F1-score for anomaly detection tasks.

🗄️ Dataset Overview & Data Quality

Synthetic campus telemetry specification — generated by generate_data.py.

Academic Simulation Notice: This project uses synthetic campus telemetry generated using thermodynamics equations, occupancy distributions, and equipment load curves. Ground-truth anomaly labels (is_anomaly, anomaly_type) are strictly isolated for evaluation and are never passed into feature matrices. Results demonstrate the methodology and do not represent verified readings from a real campus deployment.
